# AI 功能集成指南

本文档描述了如何使用新集成的 AI 智能分析功能。

## 🚀 快速开始

### 1. 环境准备

确保以下服务已启动：
- Chatlog 后端服务 (`chatlog server` - 端口 5030)
- Node.js 16.0 或更高版本

### 2. 配置 API 密钥

编辑 `.env.ai` 文件，配置你的 AI 模型 API 密钥：

```bash
# DeepSeek API 配置（推荐）
DEEPSEEK_API_KEY=your-deepseek-api-key-here

# 或 Gemini API 配置
GEMINI_API_KEY=your-gemini-api-key-here
```

### 3. 启动 AI 服务

使用一键启动脚本：

```bash
# 生产模式启动
./start-ai.sh

# 开发模式启动（支持热重载）
./start-ai.sh --dev

# 仅检查环境
./start-ai.sh --check
```

### 4. 访问应用

- 前端应用：http://localhost:8080
- AI 服务：http://localhost:3001
- 在左侧菜单中点击 "🤖 AI智能分析"

## 📊 功能特性

### 支持的分析类型

1. **编程技术分析** - 分析技术讨论、代码分享、问题解答
2. **科学学习分析** - 分析科学知识分享、学习讨论
3. **阅读讨论分析** - 分析书籍推荐、阅读心得
4. **自定义分析** - 根据自定义提示词进行分析

### 核心功能

- 🎯 **智能数据分析** - 基于 AI 的深度聊天数据分析
- 📊 **可视化报告** - 生成交互式 HTML 分析报告
- 📚 **历史管理** - 保存和管理所有分析历史
- ⏰ **定时分析** - 支持定时自动批量分析
- 🔄 **多模型支持** - 支持 DeepSeek 和 Gemini 模型

## 🛠️ 技术架构

### 后端服务 (端口 3001)
- Express + LangChain.js
- AI 模型集成 (DeepSeek/Gemini)
- 定时任务调度
- 分析历史存储

### 前端扩展
- Vue 3 + Element Plus
- AI 分析页面组件
- 实时进度显示
- 响应式设计

## 📱 使用方法

### 基本分析流程

1. **选择群聊** - 从下拉列表中选择要分析的群聊
2. **选择类型** - 选择合适的分析类型
3. **设置时间** - 选择分析的时间范围
4. **开始分析** - 点击"开始 AI 分析"按钮
5. **查看结果** - 在生成的 HTML 报告中查看分析结果

### 高级功能

- **自定义分析** - 提供自定义提示词进行专门分析
- **全屏查看** - 全屏查看详细的分析报告
- **报告下载** - 下载 HTML 格式的分析报告
- **历史查看** - 查看和管理历史分析记录

## 🔧 配置选项

### AI 模型配置

支持运行时切换 AI 模型：
- DeepSeek (推荐) - 更稳定，支持大数据量
- Gemini - 高性能多模态模型

### 定时任务配置

```bash
# 启用定时任务
ENABLE_SCHEDULED_ANALYSIS=true

# 每天早上 8 点执行
SCHEDULED_ANALYSIS_TIME=0 0 8 * * *

# 最大并发数
MAX_CONCURRENT_ANALYSIS=2
```

## 🚨 故障排除

### 常见问题

1. **连接失败**
   - 检查 Chatlog 服务是否运行 (端口 5030)
   - 确认 API 密钥是否正确配置

2. **分析超时**
   - 尝试缩小时间范围
   - 切换到 DeepSeek 模型
   - 检查网络连接

3. **无法启动服务**
   - 检查端口 3001 是否被占用
   - 确认 Node.js 版本 >= 16.0
   - 运行 `./start-ai.sh --check` 检查环境

### 日志查看

AI 服务日志会显示详细的执行信息，包括：
- API 调用状态
- 数据处理进度
- 错误信息和建议

## 📈 性能优化

- 智能重试机制，提高成功率

- 所有数据处理均在本地进行
- 不上传敏感聊天内容到第三方
